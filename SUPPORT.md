# Support

Thanks for your interest in BBSW Email Management!

This is a volunteer-maintained, open-source project. It was originally built
for BBSW Meetup Team and is shared openly under [GPLv3](LICENSE). I do **not**
provide full-time support, guaranteed responses, or any service-level
agreement.

## How to ask for help or report a problem

- **Bugs or unexpected behavior** → open a [GitHub Issue](../../issues/new/choose).
  Please include the following to reproduce the issue: what you did in each step, what you expected, what actually happened,
  and any relevant entries from the Apps Script "Executions" log
  (Extensions → Apps Script → Executions).
- **Questions about how to use the tool** → start a thread in
  [Discussions → Q&A](../../discussions).
- **Ideas for new features or improvements** → start a thread in
  [Discussions → Ideas](../../discussions).
- **Security concerns** → please email the maintainer directly rather than
  filing a public Issue.

## What to expect

- I read everything that comes in, but responses are best-effort.
  Some issues may take weeks to triage; some may never receive a response.
- I prioritize bug reports that affect **correctness or data integrity**
  (for example: unintended row deletions, sending failures, quota
  miscounting) over feature requests.
- Pull requests are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
- This software is provided "AS IS" with no warranty. See the
  [LICENSE](LICENSE) file for the full disclaimer.

## Before opening an issue

A few steps that often resolve problems faster than waiting for a reply:

1. **Read the [README](README.md)** — especially the "Managing Subscribers"
   and "How Partitions Work" sections.
2. **Check the Apps Script Executions log** for the actual error message.
   The sidebar alert is often a high-level summary; the log has the detail.
3. **Search existing [Issues](../../issues?q=is%3Aissue) and
   [Discussions](../../discussions)** — your question may already have
   been answered.
